# 😎 Marcio Bueno


**`Sobre mim`**

Comecei no balcão de uma loja de autopeças e acabei descobrindo o mundo dos marketplaces. Vendi peças online, toquei meu próprio serviço de entregas e aprendi, da maneira difícil, o que funciona e o que dá dor de cabeça em um negócio.

Foi nessa rotina que me peguei pensando: “isso poderia ser mais fácil se existisse uma ferramenta pra isso.” Foi aí que a tecnologia entrou na minha vida. Hoje estudo Análise e Desenvolvimento de Sistemas e estou aprendendo a transformar essas ideias em código.

Ainda estou no começo da jornada, e é por isso que este GitHub existe: para mostrar o que estou construindo, errando, consertando e aprendendo, um projeto de cada vez.
